# Legalia — сайт Алины Калинич

Легализация в Польше: карта побыту, CUKR, карта резидента, сталый побыт, гражданство, мельдунок. Радом, Мазовецкое воеводство.

Статичный сайт: `index.html` + `alina.jpg`, без сборки. Заявки из формы уходят в Telegram [@alinuccia3](https://t.me/alinuccia3).

## Как подключить свой домен (например, legalia.pl)

1. В репозитории: **Settings → Pages → Custom domain** — впишите домен и нажмите Save (GitHub сам создаст файл `CNAME`).
2. У регистратора домена добавьте DNS-записи:
   - для `legalia.pl` — четыре записи **A**: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - для `www.legalia.pl` — запись **CNAME** на `<ваш-логин>.github.io`
3. Когда домен заработает (от пары минут до суток), включите **Enforce HTTPS**.

Сайт можно перенести и на любой другой хостинг — достаточно скопировать эти файлы.

## Отзывы

Клиент заполняет форму «Залишити відгук» на сайте. Отзыв приходит Алине в Telegram, а сам клиент сразу видит свою карточку на сайте с пометкой «на проверке» (видна только ему).

Чтобы отзыв увидели все, его добавляют в файл `reviews.json`. На GitHub откройте файл → карандаш ✏️ → Commit changes. Через 1–2 минуты отзыв появится на сайте, и средняя оценка пересчитается сама.

```json
[
  {
    "name": "Олена К.",
    "city": "Радом",
    "service": "cukr",
    "rating": 5,
    "date": "2026-10",
    "text": "Текст отзыва как есть, на любом языке."
  }
]
```

- `name`, `text`, `rating` (1–5) — обязательные поля; `city` и `service` можно не указывать.
- `date` — год и месяц.
- Коды услуг для `service`: `work`, `jdg`, `spolka`, `study`, `family`, `cukr`, `rez`, `roots`, `kp`, `spouse`, `cit`, `najem`, `meld`, `consult`. Название показывается на выбранном языке сайта.
- Несколько отзывов разделяются запятой.

Ссылка, которая сразу открывает форму отзыва (удобно отправлять клиенту после услуги): `…/legalia/#vidguk`.
